2. Workflow

Phase A — Dendrite linker

  • Load FOV + timepoints → link the same dendrite branch across timepoints.
  • Saved to: respan\_annotator\fovN\dendrite_links.json

Phase B — Spine tracker

  • Click Load animal → review each spine across all timepoints.
  • Save & next → writes lineage + registry CSV.
  • Saved to: lineage_decisions.json, spine_registry_wide.csv under respan\_annotator\fovN\

3. Two review modes Lineage Timepoint

Lineage modeDefault. Match the same spine at each timepoint. Clear (no fate) → on save the app infers new / lost / transient spines. No artifact/ignore dropdown here.
Timepoint modeClassify only the anchor timepoint with A/I/N/L. Other timepoints keep their matches and stay editable (click spine labels or Clear). Does not auto-save — press Save & next when done.

Toggle: click Lineage mode (S) in the header, or press the physical S key (English keyboard position — works with Hebrew layout too).

4. Keyboard shortcuts (spine tracker)

Use the same physical key positions as English, even if your keyboard shows Hebrew letters. Click on the image first (not in a text field).

SToggle lineage ↔ timepoint mode
TabLineage mode: clear all timepoints. Timepoint mode (S): clear anchor TP only (other TPs unchanged).
ILineage mode: ignore on every timepoint (clears matches), save & next — use after Tab. Timepoint mode: ignore at anchor TP only (other TPs unchanged).
LTimepoint mode · LOST at anchor only (last visible = prior matched TPs; does not propagate to later TPs)
NTimepoint mode · New at this timepoint
LTimepoint mode · Lost at this timepoint

Mouse

  • Click spine label → select match at that timepoint
  • Force add spine → click to place a manual spine (x,y,z at that TP only)
  • False + → lone algorithm mistake (all other TPs must be clear)
  • Undo → revert last change on current spine
  • Mark OOF segment → hide spines inside a drawn region from the queue
